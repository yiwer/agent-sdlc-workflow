## 验证节奏

- 迭代中跑局部检查；任务或连贯批次结束跑受影响回归。
- Phase 退出跑相关集成、契约和关键路径；Goal 完成确保有最后一次代码变化后的完整/发布级绿色证据。
- 若任务或 Phase 的最新绿色命令已等同或覆盖最终门控，直接复用，不为仪式感重跑。
- 共享契约、schema、权限、安全、依赖、全局配置、并发或迁移变化时提前升级范围。
- 输入未变化时可引用最近绿色结果，不机械重复同一全量检查。

## Agent 自主与人工边界

- 当前 goal 内的代码组织、文件扩展、验证组合和可逆实现由 Agent 判断。
- 改变目标/AC、增加外部权限或付费服务、生产/真实数据、破坏性难恢复操作需要人决定。
- 局部阻塞时继续其他安全任务；只有没有安全路径时才合并询问。

## 修订

宪章变化记录动机和日期，由人确认；不要把一次性例外永久写入。
